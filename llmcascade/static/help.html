Catalog of llmcascade-owned HTTP responses, redirects, and common failure modes. Upstream provider ToS/quota errors are not listed here — only what this process returns or surfaces.

POST /v1/complete

Completion API. Auth is optional and off by default.

401 invalid or missing API key

API key rejected

REQUIRE_AUTH=true but Authorization Bearer / X-API-Key is missing or not in LLMCASCADE_API_KEYS.

Fix: Send a configured key, or set REQUIRE_AUTH=false for open local use.

429 API key rate limit exceeded

Per-key RPM budget hit

LLMCASCADE_API_RPM is set and this key exceeded requests/minute (process-local counter).

Fix: Wait for the window, raise LLMCASCADE_API_RPM, or remove the env var.

503 REQUIRE_AUTH=true but LLMCASCADE_API_KEYS is empty

Auth enabled with no keys

Auth gate is on but no keys were configured.

Fix: Set LLMCASCADE_API_KEYS=… or disable REQUIRE_AUTH.

503 router not ready

Router client not started

Request arrived before lifespan finished (or after shutdown).

Fix: Retry; check PM2/uvicorn logs if it persists.

502 safe error detail (e.g. provider HTTP 429, AllModelsExhausted…)

Completion failed after routing

Queue/submit raised — typically all eligible models failed, queue full, or a provider error. Response detail is sanitized (no raw provider bodies).

Fix: Check /dashboard budgets, cooldowns, keys, and /v1/errors. Add keys or wait for rate windows.

200 LLMResponse JSON

Success

text, model, tokens_used, latency_ms, raw.

POST /v1/embed

Embedding API. Same auth as /v1/complete. Body is prompt plus required model (must stay the same for a corpus — embeddings are not cascaded). Vectors are returned and not stored.

422 model field required

Model not specified

Embeddings live in a model-specific vector space. The router will not pick a substitute model.

Fix: Pass the registry model name, e.g. gemini-embedding-001.

502 no free-tier model succeeded for capability='embed'

All embed models failed

No eligible embedding model succeeded (missing keys, budgets, or provider errors).

Fix: Add an embedding provider key and confirm the Embedding models section on the dashboard.

Admin session & login

JWT cookie auth for dashboard/stats/admin and related /v1 data routes.

401 authentication required

Not logged in (API/JSON)

Protected JSON route without a valid llmcascade_session cookie (or expired / pwd_version mismatch).

Fix: POST /login, or change password again if the session was invalidated.

401 invalid credentials

Login failed

Username/password did not match the local admin store.

Fix: First boot is admin/admin then forced change. Reset by deleting LLMCASCADE_DATA_DIR/admin.json (recreates default).

403 password change required

Must change password

Logged in with must_change_password still true; dashboard/data routes blocked.

Fix: Complete /admin/change-password (min 8 chars).

429 too many failed attempts; try again in Ns

Login lockout

≥5 failed logins for that IP+username (process-local backoff).

Fix: Wait for the delay; restarting the process clears lockout state.

400 password must be at least 8 characters passwords do not match

Password change validation

New password rejected by form rules.

Fix: Use ≥8 characters and matching confirmation.

CSRF

Double-submit cookie on state-changing admin POSTs.

403 invalid CSRF token

CSRF check failed

Hidden field / X-CSRF-Token did not match llmcascade_csrf cookie (or cookie missing).

Fix: Hard-refresh the form page (change-password / providers re-issue matching tokens). Don’t strip cookies. Prefer HTTPS + LLMCASCADE_COOKIE_SECURE=true in production.

Startup & registry

Models load from models.yaml; keys from env (override) or encrypted admin store.

skip skipping model … — missing ENV

Model skipped

No usable key for that model (and Cloudflare also needs CLOUDFLARE_ACCOUNT_ID).

Fix: Set env key or save key in /admin/providers, then save (hot-reload).

502 / library RegistryError: no models available

Empty registry (library mode)

RouterClient without allow_empty and zero ready models. HTTP API allows empty registry so you can configure keys in the UI.

Fix: Configure at least one provider key.

warning SECRET_KEY unset — using auto-generated key…

Auto SECRET_KEY

Secret written under LLMCASCADE_DATA_DIR; JWT/Fernet derived from it.

Fix: Set a stable SECRET_KEY in .env for production so sessions/keys survive data-dir wipes consistently.

Runtime routing

Seen in events, 502 details, or library exceptions.

error request queue is full

QueueFullError

Async queue at maxsize; backpressure.

Fix: Retry later; raise max_queue / workers on RouterClient if you control the library embed.

error no free-tier model succeeded for capability=…

AllModelsExhaustedError

No eligible model left (budgets, cooldowns, or all attempts failed).

Fix: Check dashboard Free left / cooldowns / health; add another keyed provider; wait for RPM/RPD windows.

warn cooldown [rate|daily|permanent|…]

Model cooldown applied

llmcascade parked a model after a classified failure (process-local).

Fix: Wait until ready; Gemini cascade may fall through to other providers automatically.

400 unknown provider

Admin provider save

POST /admin/providers with a provider id not in models.yaml.

Fix: Use a provider listed on the providers page.

Stats / Mongo

Historical /stats UI needs Mongo; otherwise NullStatsStore.

event MongoDB connect failed: …

Mongo unavailable

Startup could not connect; live routing still works, history disabled.

Fix: Fix MONGODB_URI in .env and restart.

null store MONGODB_URI is empty — add it to .env and restart

Stats not configured

No URI set; /stats shows empty/disabled historical data.

Fix: Optional — only needed for historical charts.

HTML clients hitting protected pages.

303 → /login

Unauthenticated HTML

/dashboard, /stats, /admin/* without session.

303 → /admin/change-password

Forced password change

Valid session but must_change_password is true.

303 → /dashboard

Post-login / post-password-change

Normal success path after auth completes.

open /login · /help · /v1/status · /v1/health · /v1/complete* · /v1/embed*

Public routes

No admin session required. * /v1/complete and /v1/embed may still require API keys when REQUIRE_AUTH=true.
